📊 Manual de Balance y Finanzas

¿Para qué sirve este módulo?

El módulo de Balance y Finanzas te permite analizar la salud financiera de la clínica con reportes profesionales, gráficos en tiempo real y cálculos automáticos de rentabilidad. Es el cerebro contable del sistema.

📈 BUSINESS INTELLIGENCE (Gráficos en Tiempo Real)

La sección superior muestra 3 gráficos que se actualizan automáticamente:

Ingresos por Mes: Línea de tendencia para ver crecimiento mes a mes

Top Tratamientos: Gráfico de torta con las categorías que más facturan

Recaudación por Día: Barras que muestran qué días de la semana venden más

📄 EXPORTACIÓN CONTABLE (PDFs Profesionales)

Paso 1: Elegir período usando el Selector Rápido (Este Mes, Este Año, etc.) o fechas personalizadas

Paso 2: Elegir filtro de cuenta (todas o una específica)

Paso 3: Click en el botón según lo que necesites:

• PDF Sumas y Saldos: Balance contable por cuenta (Ingresos, Egresos, Saldo Neto)

• PDF Libro Diario: Listado completo de movimientos con fecha, hora y usuario

💰 MANAGEMENT ACCOUNTING (Contabilidad Gerencial)

Esta sección calcula automáticamente la rentabilidad real de la clínica:

Estado de Resultados (P&L):

1. Ingresos Brutos → Todo lo que se cobró
2. (-) Honorarios Médicas → Costo variable automático (60% o el % configurado)
3. (-) Costos Variables → Insumos que solo se compran si hay ventas
4. (=) MARGEN DE CONTRIBUCIÓN → Lo que queda para cubrir gastos fijos
5. (-) Costos Fijos → Alquiler, sueldos, servicios (se pagan siempre)
6. (=) EBITDA → Utilidad Operativa Pura de Sanalys

🎯 PUNTO DE EQUILIBRIO (Break-Even)

El Punto de Equilibrio es el monto mínimo que hay que facturar para NO perder dinero.

Cálculo: Costos Fijos ÷ Margen de Contribución %

Ejemplo:

- Costos Fijos del mes: $500,000
- Margen de Contribución: 40% (de cada $100 vendidos, quedan $40 después de honorarios e insumos)
- Punto de Equilibrio: $500,000 ÷ 0.40 = $1,250,000
→ Hay que facturar $1,250,000 para cubrir todos los gastos. Todo lo que se facture después de eso es ganancia.

La barra de progreso muestra qué % del punto de equilibrio ya se alcanzó.

👥 UTILIDAD NETA SANALYS (Distribución)

El EBITDA no es todo para las socias. Primero se descuenta:

1. Fondo Reserva: Un % que se guarda para emergencias (configurable en Admin)
2. Utilidad Neta: Lo que queda se divide entre las socias según su participación

Dividendo x Socia: Si hay 3 socias con partes iguales, se divide en 3.

💼 HONORARIOS A COBRAR (Staff)

Muestra cuánto le debe la clínica a cada médica en concepto de honorarios.

Cálculo: Honorarios generados - Retiros realizados = Saldo a favor

Si una médica tiene $100,000 a favor, puede hacer un retiro desde Caja por ese monto.

🔍 AUDITORÍA DE ARQUEOS DE CAJA

El botón "🔍 Ver Arqueos de Caja" arriba a la derecha permite consultar los cierres de turno históricos.

Paso 1: Seleccionar fecha

Paso 2: Filtrar por cajero (opcional)

Paso 3: Descargar el PDF del arqueo para ver movimientos del turno, billetes contados y diferencias

📅 SELECTOR RÁPIDO DE PERÍODOS

Para no tener que poner fechas manualmente, usá los botones rápidos:

• Hoy: Solo movimientos de hoy
• Ayer: Solo movimientos de ayer
• Esta Semana: Lunes a domingo de esta semana
• Este Mes: Desde el día 1 hasta hoy
• Mes Pasado: Todo el mes anterior completo
• Este Año: Desde el 1 de enero hasta hoy
• Último Trimestre: Los últimos 3 meses
• Todo: Todos los movimientos desde siempre

⚠️ CONCEPTOS CLAVE PARA ENTENDER

EBITDA: Es la ganancia operativa de la clínica (sin contar honorarios de médicas).
Margen de Contribución: Lo que queda después de pagar costos variables (honorarios + insumos).
Costos Fijos: Gastos que se pagan siempre, haya o no ventas (alquiler, sueldos).
Costos Variables: Gastos que solo ocurren si hay ventas (honorarios, insumos médicos).
