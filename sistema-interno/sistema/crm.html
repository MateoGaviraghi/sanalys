Manual de Operaciones

Módulo CRM / Pipeline

1. Captación y Registro

Usa el botón + Nuevo Prospecto para crear una ficha. Completá el Origen para que las estadísticas de marketing sean precisas. Los datos se guardan automáticamente en la nube.

2. Bitácora con Cosas Positivas y Negativas

En el panel lateral, cada nota tiene un tipo: ✅ Positivo (logros, avances, señales de compra), ⚠ Negativo (objeciones, dudas, problemas) o 📝 Neutro (informativo). Esto permite analizar el historial de cada lead de un vistazo.

3. Movimiento y Flujo

Arrastrá las tarjetas entre columnas. Cada movimiento queda registrado con fecha y hora.

4. Cierre de Ventas

Ganar: Arrastrá al cuadro verde. Confirma la conversión.
Perder: Arrastrá al cuadro rojo. Registrá el motivo para análisis de fallas.
