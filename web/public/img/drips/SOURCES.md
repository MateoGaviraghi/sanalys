# Drip bags — where these files come from

Six bags, one flat transparent still each, `<slug>.avif` with a `<slug>.webp` fallback.
692 × 1476, alpha, common canvas.

## Source

Mateo delivered `C:\Users\mateo\Downloads\sueros-sanalys\1.svg … 6.svg` on 2026-09-10.
Those files are **not vectors**: each one wraps two base64 PNGs of 1070 × 1470 inside an SVG —
one is the picture, the other is used as a luminance mask, which is how that exporter stores
transparency. Shipped as-is they weigh 945–1037 KB each (gzip barely helps: base64 of an
already-compressed PNG), which is 5.9 MB of hero.

They were therefore decoded, recomposed as RGBA, trimmed to content, placed on one common
canvas and re-encoded. Same picture, 35–39 KB per bag.

| | before | after |
|---|---|---|
| per bag | 945–1037 KB | 35–39 KB (AVIF) · 49–58 KB (WebP) |
| six bags | 5.9 MB | 218 KB |

The scripts that did it live in the session scratchpad, not in the repo: this is a one-time
conversion of a delivered asset, not a generator. The SVGs are the master — keep them.

**One common canvas, not per-bag crops.** Each bag trims to a slightly different width
(664–692 px). Cropping each to its own box makes the bag change size as the wheel turns, and
the jump is visible. All six are centred on 692 × 1476 instead, so `--suero-ar` is one number.

## Order

`1.svg … 6.svg` map to Drips 01–06 in order, confirmed by reading the printed label on each
bag: Detox Vital, Escudo Antioxidante, Recuperación Deportiva, Impulso Celular, Equilibrio
Mental, Anti-Estrés Plus.

## Note for whoever reads the labels

The labels carry a `PACIENTE:` field filled with invented names (Carolina Carmel, Manuel
Rodríguez, Griselda Suerla, Rodrigo Hernández). They come from the identity mockups and are
illegible at hero size, but they are real-looking personal names printed on a public page —
if the bags are ever shown large, ask for a version with that field blank.

## Superseded

The 288 AVIF turntable frames generated by `tools/drips/` were deleted on 2026-09-10 (D-023):
the hero no longer spins a bag, and these stills are the brand's own artwork. `tools/drips/`
still regenerates them if a turntable is ever wanted again.
