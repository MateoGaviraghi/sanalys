# `web/public/img/brand/` — brand-owned imagery, source ledger

Every image on this site is the brand's own. **No stock, not even as a placeholder** (D-018,
`docs/05-DISENO.md` §4, `docs/14-MARCA.md` §3). Sources are the print-resolution mockups inside
`brandign-sanalys/sanalys sin comprimir/Links-20251120T163502Z-1-001.zip`, which is git-ignored,
read-only and never edited or moved — the exports are read straight out of the zip.

Real photographs (CR-01) replace these files under the same names and crops when the client sends
them; nothing in the code changes. Renders of the space are always labelled as renders in the
`alt` or the caption — never presented as photographs of a clinic that has not opened.

## Crop decisions

- Default set is the one `docs/05-DISENO.md` §4 fixes: **3:4 mobile, 4:3 tablet, 21:9 desktop**.
- **`drip-01` and `drip-02` break that set on purpose.** They are a single bag hanging — a vertical
  product shot. The 21:9 and 4:3 crops both cut the hook off the top and the tubing off the bottom
  (checked on a contact sheet, not assumed), so all three crops stay portrait: 3:4 mobile, 3:4
  tablet, 3:4 desktop at 1440 × 1920. The media-query names are unchanged, so `DuotoneImage` needs
  no special case.
- **`bata-blanca` and `bata-gris` are cropped from 32 % of the source height downwards.** The figure
  in those mockups is AI-generated; `docs/14-MARCA.md` §3 allows them only cropped below the chin, as
  texture. Every crop was checked visually: no face is visible in any of the six files.
- `hero-drips` mobile is framed on Drip 01 alone; tablet and desktop carry all three bags.
